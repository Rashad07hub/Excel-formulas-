Professional Data Analyst Skills Covered These 100 questions progressively cover the Excel skills you would actually use in data analysis work:

Part 1 — Basic Data Analysis

1. Calculate total sales.
   =SUM(SalesData[Sales])
2. Calculate total profit.
   =SUM(SalesData[Profit])
3. Calculate total quantity sold.
   =SUM(SalesData[Quantity])
4. Calculate average sales per order.
   =AVERAGE(SalesData[Sales])
5. Calculate average profit per order.
   =AVERAGE(SalesData[Profit])
6. Find the maximum sales value.
  =MAX(SalesData[Sales])
7. Find the minimum sales value.
   =MIN(SalesData[Sales])
8. Find the maximum profit.
   =MAX(SalesData[Profit])
9. Find the average customer rating.
   =AVERAGE(SalesData[Customer_Rating])
10. Count total orders.
    =COUNTA(SalesData[Order_ID])

Part 10 — Advanced Data Analyst Questions

91. Calculate each order's percentage contribution to total sales.
    =[@Sales]/SUM(SalesData[Sales])
92. Calculate each product's contribution to total profit.
    =SUMIF(
     SalesData[Product_Name],
     [@Product_Name],
     SalesData[Profit]
     )/SUM(SalesData[Profit])
93. Calculate cumulative sales.
    =SUM($Q$2:Q2)
Assuming data is sorted by date:
    =SUM($S$2:S2)
94. Calculate cumulative profit.
    =SUMIFS(
     SalesData[Sales],
     SalesData[Order_Date],">="&DATE(YEAR(B2),1,1),
     SalesData[Order_Date],"<="&B2
     )
95. Calculate Year-to-Date sales.
     =SUMIFS(
      SalesData[Sales],
      SalesData[Order_Date],">="&EOMONTH(B2,-1)+1,
      SalesData[Order_Date],"<="&B2
      )
96. Calculate Month-to-Date sales.
     =IFERROR((B2-C2)/C2,0)
97. Calculate YoY sales growth.
Assume B2 contains current-year sales and C2 contains previous-year sales.
Or:
     =IFERROR(B2/C2-1,0)
98. Calculate repeat-customer percentage.
     =LET(
      u,UNIQUE(SalesData[Customer_ID]),
      orders,COUNTIF(SalesData[Customer_ID],u),
      COUNTIF(orders,">1")/COUNTA(u)
      )
99. Calculate the median order value.
     =MEDIAN(SalesData[Sales])
100. Identify sales outliers using the IQR method.
     Q1: =QUARTILE.INC(SalesData[Sales],1)
     Q3: =QUARTILE.INC(SalesData[Sales],3)
     IQR: =Q3-Q1
     Lower Bound: =Q1-1.5*IQR
     Upper Bound: =Q3+1.5*IQR
     Identify each outlier: 
     =IF(
      OR(
      [@Sales]<Lower_Bound,
      [@Sales]>Upper_Bound
      ),
      "Outlier",
      "Normal"
      )
